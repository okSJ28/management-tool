## 1. 最初にやること

### 利用者（自分の名前）を設定する

画面右上の **「👤 利用者を設定」** をクリックし、一覧から自分の名前を選んで保存します。

- 日次入力の既定の担当者になります
- 更新履歴の記録に使われます
- この設定は**使っているPCのブラウザにのみ**保存されます。PCを変えたら再設定してください

### 2つのアプリを切り替える

画面左上のタブで切り替えます。

| タブ | 用途 |
| --- | --- |
| 🧩 **開発管理** | 製造・詳細設計タスクの実績管理、生産性・品質の分析 |
| 📝 **業務予定** | 日々の予定と実績の記録 |

## 2. 業務予定管理 — 毎日の使い方

### 全体の流れ

```
【事前】📌 取組み予定を登録   「9/7〜9/18 SDLP341 製造（予定40h）」
              │
【毎朝】☀ 始業前入力          今日やることを登録
              │
【毎夕】🌙 終業前入力          やったことを工程＋進捗率で登録
              ↓
        取組み予定に自動集計（実績積上・消化率・進捗）
```

### 2-1. 取組み予定（期間の予定）を登録する ─ 事前に1回

左メニュー **「📌 取組み予定」** →  **「＋ 取組み予定を登録」**

| 入力項目 | 説明 |
| --- | --- |
| 担当者 | 自分 |
| 工程（作業区分） | 製造・詳細設計・テスト など |
| 開始日 / 終了日 | この作業に取り組む期間 |
| 予定工数(h) | **期間全体の合計**（1日分ではありません） |
| 案件名 / 作業内容 | 何の作業か |
| 開発タスクと紐付け | 選ぶと案件名・期間が自動で入ります |

登録すると予定表にガントの帯が表示されます。

> 💡 **必須ではありません。** 会議や突発対応など単発の作業は、取組み予定を作らずに日次入力だけでも構いません。

### 2-2. 始業前入力 ─ 毎朝

左メニュー **「📝 日次入力」** の左側（☀ 始業前入力）に、今日やる作業を入力します。

1. **取組み予定**を選ぶ → 工程・案件名・作業内容が**自動で入ります**
2. **予定(h)** を入力
3. 作業が複数あれば「＋ 行を追加」
4. **「💾 始業前入力を保存」**

取組み予定がない作業は「（紐づけなし）」のまま、工程と作業内容を直接入力してください。

### 2-3. 終業前入力 ─ 毎夕

同じ画面の右側（🌙 終業前入力）を使います。

1. **「⇩ 予定から取り込む」** をクリック → 朝の予定がそのままコピーされます
2. **実績(h)** と **進捗率(%)** を入力（進捗率は**必須**です）
3. 完了したものは「状況」を「完了」に
4. **「💾 終業前入力を保存」**

朝に予定していなかった作業は「＋ 行を追加」で足せます。

### 2-4. 入力状況の確認

- 画面上部に **☀ 始業前 / 🌙 終業前** の入力済み・未入力が表示されます。当日未入力だと**赤枠で警告**が出ます
- 画面下部の **「👥 チームの入力状況」** で全員の入力状況が見えます

### 2-5. 進捗の確認

「📌 取組み予定」画面で、登録した期間予定ごとに次が自動集計されます。

| 表示 | 意味 |
| --- | --- |
| 予定h | 登録した期間全体の予定工数 |
| 実績h | 紐づく日次実績の**合計** |
| 消化率 | 実績h ÷ 予定h |
| 進捗 | 紐づく実績のうち**最も新しい日の進捗率** |
| ガント帯 | 淡い色＝取組み期間／**濃い色＋✓＝実績入力済み**／破線＝予定のみ |

**「未紐づけの実績」** が出ている場合は、日次入力でその作業に取組み予定を選び直して保存すれば紐づきます。

## 3. 開発プログラム管理 — タスクの登録と分析

### 3-1. タスクを登録する

**「📋 一覧・入力」** → 右上の **「＋ 新規登録」**

種別（製造／詳細設計）を選び、プログラムID・案件名・担当者・期間・step数・工数・指摘件数などを入力します。

**換算step・生産性・品質などの指標は自動計算**されるため、入力は不要です（グレー表示）。

### 3-2. 既存データを直接編集する

一覧表の **セルをダブルクリック** するとその場で編集できます。
計算項目や読み取り専用の項目をクリックすると詳細画面が開きます。

### 3-3. Excelから取り込む

**「🔁 取込 / 出力」** → 「📂 フォルダ内のExcelを取込」

| 取込方法 | 動作 |
| --- | --- |
| 更新＋追加（推奨） | 同じ「種別＋プログラムID＋案件名＋開始日」は上書き、無ければ追加 |
| すべて追加 | 重複を判定せず全部追加 |
| 全件置換 | 既存を全部消して入れ替え |

> ⚠️ Excelの取込は**1分ほどかかる**ことがあります。画面が固まったように見えても待ってください。

### 3-4. 見る・分析する

| 画面 | 分かること |
| --- | --- |
| 🏠 ダッシュボード | 全体状況、**誰が何を何本やったか**（担当者別 実施本数）、月次推移 |
| 👥 担当者ビュー | 担当者ごとの稼働状況・今月実績 |
| 📆 ガントチャート | 誰がいつ何をやるかの期間俯瞰 |
| 📈 分析 | 観点（担当者・案件・月など）× 指標のグラフ |
| 🔀 クロス集計 | 任意の2軸で件数を集計 |
| ✅ 実績入力確認 | 担当者 × 月の入力状況。クリックで 完了／対象外／未入力 を切替 |

#### 「📊 担当者別 実施本数」の見方

担当者ごとに **ES / NET の2行** で、区分（新規・修正）とリソース区分（JN・RD・bjex など）の本数を表示します。

- 上部のプルダウンで **期間**（今月／今年度／全期間）、**対象**（完了のみ／全ステータス）、**種別** を切り替えられます
- 担当者・システム列は固定されるので、**横スクロール**しても誰の行か分かります
- 行をクリックするとその担当者のビューに移動します

## 4. 設定した項目がどこに反映されるか

**「⚙ 設定」** で追加・変更した項目が、どの画面に反映されるかの一覧です。
（設定は全利用者で共有されます。変更すると全員の画面に反映されます）

### 4-1. 計算パラメータ

保存すると **全タスクの指標が再計算されます**。

| 設定項目 | 反映先 |
| --- | --- |
| 母体step 係数 / 新規step 係数 / 修正step 係数 | **換算step** → 一覧・入力、ダッシュボード、分析、クロス集計、Excel/CSV出力 |
| 月換算生産性の基準時間 | **月換算生産性** → 一覧・入力、ダッシュボード、担当者ビュー、分析 |
| 1人日あたり時間 | 「約○人日」表示 → ダッシュボード、日次入力（基準h）、取組み予定、予定サマリ |
| 年度開始月 | 年度の区切り → 分析（年度軸）、実績入力確認、クロス集計、ダッシュボード（今年度） |
| 目標 月換算生産性 / 目標 品質 | 目標値の表示と色分け → ダッシュボード、一覧・入力、分析 |

### 4-2. 選択肢マスタ

| 設定項目 | 主な反映先 | 補足 |
| --- | --- | --- |
| **ステータス定義** | 一覧・入力の選択肢／**ガントチャートの色分け**／ダッシュボード／実績入力確認 | 値と色を設定できます |
| **業務予定：作業区分**<br>（＝**工程**） | **日次入力**の工程列／**取組み予定**／チーム予定ボードの色分け／予定サマリの集計軸／ダッシュボード「本日の業務予定」／担当者ビュー | 業務予定側で最もよく使う設定です。値と色を設定できます |
| **業務予定：ステータス** | 日次入力の「状況」列／取組み予定のステータス／チーム予定ボードの絞り込み | 予定・実施中・完了・中止 |
| **リソース分類**<br>（グループ分け） | **分析画面の「リソース分類」軸のみ** | 他の画面では使いません。分類されていない値は「その他」になります |
| **メンバー（担当者）** | 一覧・入力の担当者①②／担当者ビュー／ガントの絞り込み／実績入力確認／**日次入力・取組み予定の担当者**／利用者設定 | データに現れた名前は自動で追加されます |
| **案件名** | 一覧・入力の案件名候補／ガント・分析・クロス集計・予定ボードの絞り込み／日次入力・取組み予定の候補 | 自由入力もできます。データに現れた案件は自動追加 |
| **リソース区分** | 一覧・入力のリソース区分／**ダッシュボード「担当者別 実施本数」の列**／分析・クロス集計の軸／ガントのグループ分け | 追加してもリソース分類に自動では入りません（4-3参照） |
| **システム** | 一覧・入力のシステム／**ダッシュボード「担当者別 実施本数」の行（ES / NET）**／分析・クロス集計の軸 | ES・NET以外は「その他」行にまとまります |
| **区分** | 一覧・入力の区分／**ダッシュボード「担当者別 実施本数」の列**／分析・クロス集計の軸 | 新規・修正 など |
| **使用エディタ** | 一覧・入力の使用エディタ／分析・クロス集計の軸 | 製造のみ |
| **設計種別** | 一覧・入力の設計種別 | 詳細設計のみ |
| **実績入力の状態** | **実績入力確認**画面のセルの値 | 完了・対象外・未入力 |

### 4-3. よくある注意点

**「リソース区分」に追加しただけでは分析画面のグループに入りません**

リソース区分（例：`帳票`）を追加したら、**「リソース分類」でもグループに追加**してください。
していない場合、分析画面の「リソース分類」軸では「その他」に分類されます。

```
リソース区分に「帳票」を追加
      ↓
ダッシュボードの「担当者別 実施本数」には すぐ列として出る
分析画面の「リソース分類」軸では「その他」になる
      ↓
「リソース分類」で バッチ系 などに追加すると正しく集計される
```

**選択肢を消しても既存データは消えません**

マスタから値を削除しても、その値が入っているタスクや予定はそのまま残ります。
一覧には表示されますが、新規入力の選択肢には出なくなります。

**マスタは全員共有です**

設定変更は即座に全利用者に反映されます（他の人の画面は最大20秒で自動更新）。

## 5. 困ったときは

| 症状 | 対処 |
| --- | --- |
| 画面が真っ白・古い表示のまま | `Ctrl` + `F5` で強制リロード |
| 「サーバー応答がありません」 | 通信が不安定です。少し待って再読み込み |
| 保存できない・「工程を選択してください」 | 工程（作業区分）は必須です。実績は進捗率も必須です |
| 他の人の入力が見えない | 20秒ごとに自動更新されます。急ぐ場合は再読み込み |
| 間違えて消してしまった | 「🔁 取込 / 出力」→「バックアップから復元」、または管理者にご連絡ください |
| Excelの取込が終わらない | 1分程度かかります。そのままお待ちください |

### データの保存について

- 入力は**保存ボタンを押した時点でサーバーに保存**されます
- 保存のたびに自動バックアップが作られます（最新30世代）
- 「🔁 取込 / 出力」画面の下部で、データベースの場所と最終更新日時を確認できます

### 自動更新について

他の人が入力した内容は **20秒ごとに自動で反映**されます。
反映されると画面右下に「他の利用者による更新を反映しました」と表示されます。

> ⚠️ 日次入力で**編集中の未保存の内容は失われません**が、こまめに保存することをおすすめします。
