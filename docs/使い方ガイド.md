## 1. 最初にやること

### ログインする

URL を開くとログイン画面が表示されます。**ID** と **パスワード** を入力して「ログイン」を押します。

- ID は社員番号です（例: `A250028`）。**初期パスワードは ID と同じ**です
- ログインした人の名前が、日次入力の既定の担当者と更新履歴の記録に使われます
- ログインは **12 時間** 有効です。期限が切れるとログイン画面が出るので、もう一度ログインしてください
  （同じ ID で入り直せば、編集中の画面はそのまま続けられます）
- ID・パスワードが分からないときは管理者（大場・岡本）に問い合わせてください

### パスワードを変更する（初回に必ず実施）

画面右上の **「👤 自分の名前」** →「🔑 パスワード変更」で、現在のパスワードと新しいパスワード（4文字以上）を入力します。
初期パスワードのままだと、ID を知っている人が誰でもログインできてしまいます。

同じ画面の **「ログアウト」** でログアウトできます。共用 PC ではログアウトしてから離席してください。

### 権限について

| 権限 | できること |
| --- | --- |
| 一般 | タスク・予定の登録と編集、Excel / CSV の取込（全件置換を除く）、各種出力。業務予定（日次入力・取組み予定）は **自分の分のみ** 登録・編集できます（他の人の分は閲覧のみ） |
| 管理者 | 上記に加えて **全員分の業務予定の入力**・**ユーザー管理**・**設定（マスタ・計算パラメータ）の編集**・**バックアップからの復元**・**取込の全件置換**・**タスクの一括削除** |
| 特権管理者 | 管理者と同じ。閲覧が主な方向けで、**担当者に含まれません**（日次入力・実績入力確認・担当者一覧の対象外） |

一般ユーザーには左メニューに「⚙ 設定」が表示されません。マスタの追加・変更が必要なときは管理者に依頼してください。

### 2つのアプリを切り替える

画面左上のタブで切り替えます。

| タブ | 用途 |
| --- | --- |
| 🧩 **開発管理** | 製造・詳細設計タスクの実績管理、生産性・品質の分析 |
| 📝 **業務予定** | 日々の予定と実績の記録 |

## 2. 業務予定管理 — 毎日の使い方

### 全体の流れ

```
【事前】📌 取組み予定を登録   「9/7〜9/18 SDLP341 製造（予定40h）」
              │
【毎朝】☀ 始業前入力          今日やることを登録
              │
【毎夕】🌙 終業前入力          やったことを工程＋進捗率で登録
              ↓
        取組み予定に自動集計（実績積上・消化率・進捗）
```

### 2-1. 取組み予定（期間の予定）を登録する ─ 事前に1回

左メニュー **「📌 取組み予定」** →  **「＋ 取組み予定を登録」**

| 入力項目 | 説明 |
| --- | --- |
| 担当者 | 自分（一般ユーザーは自分に固定。管理者は他の人の分も登録できます） |
| 工程（作業区分） | 製造・詳細設計・テスト など |
| 開始日 / 終了日 | この作業に取り組む期間 |
| 予定工数(h) | **期間全体の合計**（1日分ではありません） |
| 案件名 / 作業内容 | 何の作業か |
| 開発タスクと紐付け | 自分が担当の開発タスクから選べます。選ぶと案件名・期間が自動で入ります |

登録すると予定表にガントの帯が表示されます。
取組み予定の登録は、この「📌 取組み予定」画面から行います（日次入力の画面からは登録できません）。

> 💡 **必須ではありません。** 会議や突発対応など単発の作業は、取組み予定を作らずに日次入力だけでも構いません。

左メニュー **「📝 日次入力」** は、1つの作業を1行で管理する表です。
同じ行の **左側が ☀ 予定（朝に入力）**、**右側が 🌙 実績（夕方に入力）** です。

### 2-2. 始業前入力 ─ 毎朝

1. **「＋ 作業を追加（予定）」** で行を追加
2. **取組み予定**を選ぶ → 工程・案件名・作業内容が**自動で入ります**
3. **予定h** を入力
4. 作業が複数あれば 1〜3 を繰り返す
5. 画面下の **「💾 保存」**（または **Ctrl+S**）

取組み予定がない作業は「（紐づけなし）」のまま、工程と作業内容を直接入力してください。
PJCD・作業コードを入れたいときは作業内容の右の 🔗 を押します。
前日と同じ作業が続くときは **「⧉ 前営業日の予定を複製」** が便利です（定例予定は各日に登録済みなので複製されません）。

**予定の合計は 7.5h（1人日）が基準です。** 予定h の合計が 7.5h に足りないと、合計行が赤くなり、
画面下に「⚠ 予定の合計 ○h（基準 7.5h に ○h 不足）」と表示されます。保存しようとすると確認が出るので、
予定の入れ漏れがないか見直してください（半休などで本当に少ない日は「このまま保存」で保存できます）。
予定がすべて「休暇」の日は対象外です。

#### 毎週ある予定（定例予定）をまとめて登録する

毎週木曜の課会のように決まった曜日にある予定は、**「🔁 定例予定を登録」**（日次入力・チーム予定ボードの上部）で一度に登録できます。

1. **曜日**（複数可）と **開始日・終了日**（最長 1 年。初期値は今日〜90日後）を選ぶ
2. **工程**・**予定工数(h)**（1回あたり。30分なら 0.5）を入力。案件名・作業内容・PJCD・作業コードは必要に応じて
3. 下に「対象日 ○ 日 → 予定を ○ 件登録します」と出るので確認して **「登録」**

- 登録した予定は各日の予定として入り、日次入力では **「🔁 定例」**、チーム予定ボードでは **🔁** が付きます
- 同じ日に同じ工程・作業内容の予定がすでにある日は登録されません
- **祝日・会社の休日も登録されます。** 不要な日はその日の予定を個別に削除してください
- その日だけ時間を変える・休むときは、その日の行を直接直す・消すだけで OK です
- 会議がなくなったときは、チーム予定ボードで定例の予定を開き **「この日以降の定例を削除」** を押すと、その日以降の分をまとめて削除できます（入力済みの実績は残ります）
- 管理者は担当者を複数選んで、チーム全員分の定例をまとめて登録できます
- 日次入力で保存していない変更があるときは、先に保存してから登録してください

### 2-3. 終業前入力 ─ 毎夕

朝に入力した**同じ行の右側（🌙 実績）**を埋めます。行を作り直す必要はありません。

1. **進捗率** をボタン（0・25・50・75・100）で選ぶ（細かい値は右の欄に数値で入力）。進捗率は**必須**です
2. **実績h** は予定どおりなら**空欄のままで OK**（薄く表示されている予定h がそのまま実績になります）。違ったときだけ入力します
3. 進捗率 100 にすると「状況」が自動で「完了」になります
4. **「💾 保存」**（または **Ctrl+S**）

- 朝に予定していなかった作業は **「＋ 予定外の作業を追加（実績のみ）」** で追加します
- 「差」の列に 実績h − 予定h が表示されます（超過は赤、余りは青）
- 実績を取り消したいときは、実績h と進捗率を空にして保存します（予定は残ります）。行ごと消すときは右端の ✕ です
- 保存していない変更があると、画面下に **「未保存の変更 ○ 件」** と表示されます。
  そのまま日付や担当者を切り替えたり、他の画面へ移動したり、画面を閉じようとすると確認が出ます（「キャンセル」で入力に戻れます）
- 予定h・実績h は 1日あたり **0〜24** の範囲で入力します。進捗率は 0〜100 で、範囲を超えた値は自動で 0 / 100 に直ります

### 2-4. 入力状況の確認

- 画面上部に **☀ 始業前 / 🌙 終業前** の入力済み・未入力が表示されます。予定の合計が 7.5h に足りないときは「⚠ … 不足」と表示されます
- その日の予定がすべて **休暇** の場合、終業前入力は不要です（「✓ 休暇のため不要」と表示されます）
- 表の下の **「📋 前回の入力」** に、前回（直近の入力がある日。月曜なら金曜）の入力内容が表示されます。参照用で編集はできません。前回分を直すときは「‹ 前日」でその日に移動してください
- （管理者のみ）画面下部の **「👥 チームの入力状況」** を開くと全員の入力状況が見えます。予定の合計が 7.5h に足りない人は「⚠ ○h 不足」と表示されます。名前をクリックするとその人の表に切り替わります
- 左メニュー **「🗓 チーム予定ボード」** では、全員の予定・実績を日付ごとに見られます。各日付は **☀ 予定** と **🌙 実績** の 2 列に分かれています（「種別」で絞り込むと片方だけ）。表示日数は 7 日（初期値）か 14 日です
  - 一般ユーザーは自分の行の空欄をクリックして登録できます（予定の列なら予定、実績の列なら実績）。他の人の予定・実績は開くと閲覧のみ（「記録を表示」）になります

### 2-5. 進捗の確認

「📌 取組み予定」画面で、登録した期間予定ごとに次が自動集計されます。

| 表示 | 意味 |
| --- | --- |
| 予定h | 登録した期間全体の予定工数 |
| 実績h | 紐づく日次実績の**合計** |
| 消化率 | 実績h ÷ 予定h |
| 進捗 | 紐づく実績のうち**最も新しい日の進捗率** |
| ガント帯 | 淡い色＝取組み期間／**濃い色＋✓＝実績入力済み**／破線＝予定のみ |

**「未紐づけの実績」** が出ている場合は、日次入力でその作業に取組み予定を選び直して保存すれば紐づきます。

## 3. 開発プログラム管理 — タスクの登録と分析

### 3-1. タスクを登録する

**「📋 一覧・入力」** → 一覧の上の **「＋ 行を追加」**（「👥 メンバー」画面の **「＋ タスク追加」** からも登録できます）

種別（製造／詳細設計）を選び、プログラムID・案件名・担当者・期間・step数・工数・指摘件数などを入力します。

**換算step・生産性・品質などの指標は自動計算**されるため、入力は不要です（グレー表示）。

### 3-2. 既存データを直接編集する

一覧表の **セルをダブルクリック** するとその場で編集できます。
計算項目や読み取り専用の項目をクリックすると詳細画面が開きます。

### 3-3. Excelから取り込む

**「🔁 取込 / 出力」** → 「📂 フォルダ内のExcelを取込」

| 取込方法 | 動作 |
| --- | --- |
| 更新＋追加（推奨） | 同じ「種別＋プログラムID＋案件名＋開始日」は上書き、無ければ追加 |
| すべて追加 | 重複を判定せず全部追加 |
| 全件置換（管理者のみ） | 既存を全部消して入れ替え。一般ユーザーには表示されません |

> ⚠️ Excelの取込は**1分ほどかかる**ことがあります。画面が固まったように見えても待ってください。

### 3-4. 見る・分析する

| 画面 | 分かること |
| --- | --- |
| 🏠 ダッシュボード | 全体状況、**誰が何を何本やったか**（担当者別 実施本数）、月次推移 |
| 👥 担当者ビュー | 担当者ごとの稼働状況・今月実績 |
| 📆 ガントチャート | 誰がいつ何をやるかの期間俯瞰 |
| 📈 分析 | 観点（担当者・案件・月など）× 指標のグラフ |
| 🔀 クロス集計 | 任意の2軸で件数を集計 |
| ✅ 実績入力確認 | 担当者 × 月の入力状況。クリックで 完了／対象外／未入力 を切替 |

#### 「📊 担当者別 実施本数」の見方

担当者ごとに **ES / NET の2行** で、区分（新規・修正）とリソース区分（JN・RD・bjex など）の本数を表示します。

- 上部のプルダウンで **期間**（今月／今年度／全期間）、**対象**（完了のみ／全ステータス）、**種別** を切り替えられます
- 担当者・システム列は固定されるので、**横スクロール**しても誰の行か分かります
- 行をクリックするとその担当者のビューに移動します

## 4. 設定した項目がどこに反映されるか

**「⚙ 設定」**（管理者のみ）で追加・変更した項目が、どの画面に反映されるかの一覧です。
（設定は全利用者で共有されます。変更すると全員の画面に反映されます）

### 4-0. ユーザー管理（管理者向け）

設定画面の先頭の **「👥 ユーザー管理」** で行います。

| 操作 | 方法 |
| --- | --- |
| 追加 | 「＋ ユーザー追加」→ ID・氏名・担当者名・権限を入力。**初期パスワードは ID と同じ**です |
| 編集 | 「編集」→ 氏名・担当者名・権限を変更（ID は変更できません） |
| パスワードを忘れた | 「PW初期化」→ パスワードが ID と同じ値に戻ります。本人に変更してもらってください |
| 削除 | 「削除」→ 登録済みのタスクや予定は残ります。自分自身は削除できません |

- **担当者名** はタスク・予定の担当者名と一致させてください。未登録の名前ならメンバーに自動で追加されます
- 権限を **特権管理者** にすると、その人は担当者一覧から外れます（日次入力の入力対象・実績入力確認の集計対象になりません）
- 管理者（特権管理者を含む）が 1 人だけのときは、その人を一般に変更したり削除したりできません
- 退職・異動した人は、マスタの「担当者」から ✕ で削除してください。過去のタスクに名前が残っていても担当者一覧には再表示されません（タスクの記録・集計は残ります）

### 4-1. 計算パラメータ

保存すると **全タスクの指標が再計算されます**。
空欄や範囲外の値（年度開始月が 1〜12 以外、1人日あたり時間が 1〜24 以外、月換算の基準時間が 1 未満、係数・目標値が負の値など）は保存できません。
設定画面はカード（計算パラメータ・各マスタ）ごとに保存します。1枚を保存しても、他のカードで編集中の内容は消えません。

| 設定項目 | 反映先 |
| --- | --- |
| 母体step 係数 / 新規step 係数 / 修正step 係数 | **換算step** → 一覧・入力、ダッシュボード、分析、クロス集計、Excel/CSV出力 |
| 月換算生産性の基準時間 | **月換算生産性** → 一覧・入力、ダッシュボード、担当者ビュー、分析 |
| 1人日あたり時間 | 「約○人日」表示 → ダッシュボード、日次入力（基準h）、取組み予定、予定サマリ |
| 年度開始月 | 年度の区切り → 分析（年度軸）、実績入力確認、クロス集計、ダッシュボード（今年度） |
| 目標 月換算生産性 / 目標 品質 | 目標値の表示と色分け → ダッシュボード、一覧・入力、分析 |

### 4-2. 選択肢マスタ

| 設定項目 | 主な反映先 | 補足 |
| --- | --- | --- |
| **ステータス定義** | 一覧・入力の選択肢／**ガントチャートの色分け**／ダッシュボード／実績入力確認 | 値と色を設定できます |
| **業務予定：作業区分**<br>（＝**工程**） | **日次入力**の工程列／**取組み予定**／チーム予定ボードの色分け／予定サマリの集計軸／ダッシュボード「本日の業務予定」／担当者ビュー | 業務予定側で最もよく使う設定です。値と色を設定できます |
| **業務予定：ステータス** | 日次入力の「状況」列／取組み予定のステータス／チーム予定ボードの絞り込み | 予定・実施中・完了・中止 |
| **リソース分類**<br>（グループ分け） | **分析画面の「リソース分類」軸のみ** | 他の画面では使いません。分類されていない値は「その他」になります |
| **メンバー（担当者）** | 一覧・入力の担当者①②／担当者ビュー／ガントの絞り込み／実績入力確認／**日次入力・取組み予定の担当者**／ユーザー管理の担当者名候補 | データに現れた名前は自動で追加されます |
| **案件名** | 一覧・入力の案件名候補／ガント・分析・クロス集計・予定ボードの絞り込み／日次入力・取組み予定の候補 | 自由入力もできます。データに現れた案件は自動追加 |
| **リソース区分** | 一覧・入力のリソース区分／**ダッシュボード「担当者別 実施本数」の列**／分析・クロス集計の軸／ガントのグループ分け | 追加してもリソース分類に自動では入りません（4-3参照） |
| **システム** | 一覧・入力のシステム／**ダッシュボード「担当者別 実施本数」の行（ES / NET）**／分析・クロス集計の軸 | ES・NET以外は「その他」行にまとまります |
| **区分** | 一覧・入力の区分／**ダッシュボード「担当者別 実施本数」の列**／分析・クロス集計の軸 | 新規・修正 など |
| **使用エディタ** | 一覧・入力の使用エディタ／分析・クロス集計の軸 | 製造のみ |
| **設計種別** | 一覧・入力の設計種別 | 詳細設計のみ |
| **実績入力の状態** | **実績入力確認**画面のセルの値 | 完了・対象外・未入力 |

### 4-3. よくある注意点

**「リソース区分」に追加しただけでは分析画面のグループに入りません**

リソース区分（例：`帳票`）を追加したら、**「リソース分類」でもグループに追加**してください。
していない場合、分析画面の「リソース分類」軸では「その他」に分類されます。

```
リソース区分に「帳票」を追加
      ↓
ダッシュボードの「担当者別 実施本数」には すぐ列として出る
分析画面の「リソース分類」軸では「その他」になる
      ↓
「リソース分類」で バッチ系 などに追加すると正しく集計される
```

**選択肢を消しても既存データは消えません**

マスタから値を削除しても、その値が入っているタスクや予定はそのまま残ります。
一覧には表示されますが、新規入力の選択肢には出なくなります。

**マスタは全員共有です**

設定変更は即座に全利用者に反映されます（他の人の画面は最大20秒で自動更新）。

## 5. 困ったときは

| 症状 | 対処 |
| --- | --- |
| 画面が真っ白・古い表示のまま | `Ctrl` + `F5` で強制リロード |
| 「サーバー応答がありません」 | 通信が不安定です。少し待って再読み込み |
| 保存できない・「工程を選択してください」 | 工程（作業区分）は必須です。実績は進捗率も必須です |
| 保存時に「予定の合計が基準に足りません」と出る | 予定h の合計が 7.5h 未満です。入れ漏れがあれば「キャンセル」して追加してください。半休などで少ないのが正しければ「このまま保存」 |
| 定例予定を止めたい・間違えて登録した | チーム予定ボードで 🔁 の付いた予定を開き「この日以降の定例を削除」 |
| 「予定(h)・実績(h) は 0〜24 の範囲で入力してください」 | 1日の工数は 0〜24 時間で入力してください（取組み予定の予定工数は期間全体の合計なので 24 を超えても構いません） |
| 「この操作は管理者のみ実行できます」 | 全件置換・一括削除などは管理者に依頼してください |
| 他の人の入力が見えない | 20秒ごとに自動更新されます。急ぐ場合は再読み込み |
| 間違えて消してしまった | 管理者にご連絡ください（管理者は「🔁 取込 / 出力」→「バックアップから復元」で戻せます） |
| ログインできない | ID・パスワードを確認してください。忘れた場合は管理者に「PW初期化」を依頼してください |
| 「ログインの有効期限が切れました」 | もう一度ログインしてください。同じ ID なら編集中の内容は残っているので、再度保存してください |
| 「この画面は管理者のみ利用できます」 | 設定の変更は管理者に依頼してください |
| 「保存していない変更があります。破棄して移動しますか？」 | 「キャンセル」で元の画面に戻り、保存してから移動してください。「OK」を押すと入力中の内容は破棄されます |
| Excelの取込が終わらない | 1分程度かかります。そのままお待ちください |

### データの保存について

- 入力は**保存ボタンを押した時点でサーバーに保存**されます
- 保存のたびに自動バックアップが作られます（最新30世代）
- 「🔁 取込 / 出力」画面の下部で、データベースの場所と最終更新日時を確認できます

### 自動更新について

他の人が入力した内容は **20秒ごとに自動で反映**されます。
反映されると画面右下に「他の利用者による更新を反映しました」と表示されます。

> ⚠️ 日次入力・設定で**未保存の変更があるあいだは自動反映を止めます**（入力中の内容は消えません）。保存すると自動反映が再開します。
